## 📌 About the Project

Water pollution is a critical environmental issue. This project combines **IoT sensors** and **Machine Learning** to:
- Detect and classify polluted items in water bodies
- Collect data from water sensors in real time
- Predict pollution levels using a trained ML classifier

Built as part of **ATMAN 2.0** — a national-level hackathon by **TIH Foundation** focused on sustainable technology solutions.

---

## ✨ Features

- Real-time water quality monitoring using IoT sensors
- ML-based pollutant classification model
- Data collection and logging pipeline
- Pollution severity prediction
